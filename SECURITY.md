# Security policy

Please report suspected vulnerabilities privately to
[support@cweb.app](mailto:support@cweb.app), with the subject
**Security report: cWeb Forge Python SDK**. Do not open a public issue with
exploit details, credentials or private customer data.

Include the affected SDK version, Python version, impact and a minimal
reproduction using synthetic data. We will coordinate investigation and
disclosure with you. Use the latest published SDK version; older releases do not
have a separate maintenance guarantee.

If a credential has been exposed, revoke or rotate it immediately. Removing it
from a file or Git commit does not invalidate copies that may already exist.
